3.2 Network Devices

  • Router: Provides Internet connectivity and acts as the network gateway.
  • Managed Switch: Connects wired computers and network devices.
  • Server: Manages network and database services.
  • Wireless Access Point: Provides wireless network access.

3.3 Network Topology

Star Topology

NEXUS Cyber Café uses a Star Topology where all computers and network devices are connected to a central managed switch.

  • Easy to install and manage.
  • Easy to troubleshoot network problems.
  • Failure of one computer does not affect other computers.
  • Easy to expand when more computers are added.
  • Suitable for a cyber café environment.
